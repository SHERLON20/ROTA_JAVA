🚗 Sistema de Rotas em Java

Aplicação desenvolvida em Java para cálculo e gerenciamento de rotas, utilizando conceitos fundamentais de lógica de programação, estruturas condicionais e manipulação de dados.

O projeto simula um sistema de roteamento, permitindo trabalhar com trajetos, distâncias e organização de caminhos de forma prática e objetiva.

🎯 Objetivo do Projeto

O principal objetivo deste projeto é praticar:

Lógica de programação
Estruturas de decisão
Entrada e saída de dados
Organização de algoritmos
Desenvolvimento backend com Java
Manipulação de rotas e trajetos

Além disso, o sistema demonstra conceitos utilizados em problemas de otimização e roteamento presentes em sistemas logísticos e de transporte.

☕ Tecnologias Utilizadas
Java
Programação Orientada a Objetos (POO)
Console Application

▶️ Como Executar o Projeto
1️⃣ Clone o repositório
git clone https://github.com/SHERLON20/ROTA_JAVA.git
2️⃣ Acesse a pasta do projeto
cd ROTA_JAVA
3️⃣ Compile o arquivo Java
javac rota.java
4️⃣ Execute o sistema
java rota
